# New Game Themes Replacement for SFMB DEMO 2.1

Colección de temas y recursos gráficos para el proyecto.

## Contenido
- Temas personalizados
- Texturas y fondos
- Recursos gráficos
- BGM, Sonidos

## Instalación / Uso
1. Ve a la sección de **Releases** a la derecha de la página principal.
2. Descarga el paquete de recursos `.zip`.
3. Extrae el contenido en la carpeta correspondiente de tu proyecto.
